\newcommand{\paragrafblogu}[1]{%
  \paragraph{Section #1.}
  The purpose of this page is to give the search tests a document with
  real, extractable text. The words on the page are ordinary English so
  that the token ``the'' appears many times on every page, which is what
  the viewer searches for. The layout is deliberately plain: no figures,
  no bibliography, no external packages beyond the page geometry.

  The second paragraph exists so that the page has enough height for the
  scroll range to be non zero. The viewer test moves the scroll bar to the
  middle of the range and then checks that restoring the search results
  does not move it back to the top. Without enough text the range would be
  zero and the gate would run empty.
}
